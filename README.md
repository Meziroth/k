# Meziroth Kodi Repo

Kodi file manager source: `https://meziroth.github.io/k/`

Contents:
- `repo/repository.meziroth` - the repository add-on
- `repo/plugin.program.mezirothwizard` - Meziroth Wizard (OpenWizard 2.0.7, rebranded, pointed at `wizard/builds.txt`)
- `repo/zips` - generated by `_repo_generator.py` (addons.xml, md5, add-on zips)
- `wizard/builds.txt` - build list read by the wizard
- `wizard/august2025_guisettings.zip` - GUI/skin settings applied after the build installs

## Publish (one time)
1. Create a public GitHub repo named `k` under `meziroth`, default branch `main`.
2. Copy `august2025_guisettings.zip` into `wizard/`.
3. Push everything in this folder to `main`.
4. Settings -> Pages -> Source: Deploy from branch, `main` / root. Save.
5. Releases -> Draft a new release -> tag `august2025` -> attach `august2025-public.zip` -> Publish.
   (The build is ~480 MB; GitHub blocks files over 100 MB in the repo itself, so it has to be a Release asset.)

## Install on a device
1. Settings -> System -> Add-ons -> enable Unknown sources.
2. File manager -> Add source -> `https://meziroth.github.io/k/` -> name it `meziroth`.
3. Add-ons -> Install from zip file -> meziroth -> `repository.meziroth-1.0.0.zip`.
4. Install from repository -> Meziroth Repository -> Program add-ons -> Meziroth Wizard.
5. Open the wizard -> Builds -> August 2025 -> Fresh Install.

## Updating
- New build: upload a new zip as a new Release, add/edit an entry in `wizard/builds.txt` (bump `version` to trigger update prompts), push.
- Changed an add-on: bump its `version` in its addon.xml, run `python _repo_generator.py`, push.
- Changed the repo add-on itself: also copy the new zip to the root and update `index.html`.
